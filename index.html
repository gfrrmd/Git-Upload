Git-Upload

Unggah file ke GitHub tanpa terminal.

Unggah file atau zip, buat repositori dan branch, lalu unduh kembali kapan saja. Semuanya dari browser, di HP maupun komputer.

Lihat fitur
  • Token hanya disimpan di tab ini
  • Isi zip diekstrak langsung ke repositori
  • Satu commit untuk setiap unggahan

Token tetap di browser kamu

Git-Upload tidak punya server. Permintaan langsung dari browser ke GitHub, dan token terhapus saat tab ditutup.

Pertanyaan yang sering diajukan

Token hanya disimpan di sesi tab browser dan hanya dikirim ke api.github.com. Tidak ada server Git-Upload yang menerimanya. Tutup tab dan token hilang. Sebaiknya buat token khusus, lalu hapus di pengaturan GitHub jika tidak dipakai lagi.

Personal access token (classic) dengan izin repo. Izin itu cukup untuk mengunggah, mengunduh, membuat repositori, dan membuat branch.

Zip dibuka di browser, lalu seluruh isinya diunggah langsung ke folder tujuan tanpa folder pembungkus, dalam satu commit. Zip berpassword belum didukung. Pilih mode Unggah file asli jika zip ingin disimpan apa adanya.

Satu file maksimal sekitar 100 MB, sesuai batas GitHub. Satu kali unggah maksimal 3000 file, dan unduh repositori maksimal 2000 file atau 300 MB. Di HP dengan memori kecil, file besar bisa terasa lambat.

Belum. Branch tujuan harus sudah ada. Repositori yang dibuat lewat Git-Upload otomatis berisi README, jadi langsung bisa dipakai. Untuk repositori kosong dari tempat lain, tambahkan satu file dulu lewat github.com.

Bisa. Ketuk ikon palet di pojok kanan atas, lalu pilih mode otomatis, terang, atau gelap, salah satu dari delapan warna aksen, atau warna kustom. Pilihanmu diingat di browser ini.
