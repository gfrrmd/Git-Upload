Drop in a file or a zip, choose where it goes, and Git-Upload commits it for you. Create repositories and branches, browse your code, and download anything back out.

Everything a quick push needs

Upload as is

Send any file to a repository, branch and folder of your choice. Existing files are updated in place.

Extract zip archives

Archives are unpacked in your browser and their contents land directly at the destination, with no wrapper folder, in a single commit.

Repositories and branches

Create a public or private repository, or branch off any existing branch, without leaving the page.

Download the whole repository

Fetch any branch as a complete zip file, including private repositories you can access.

Download a single file

Pull one file by path, or open the browser and download straight from the list.

Browse and delete

Move through folders, then remove a file or an entire folder in one commit.

Your token never leaves your browser

Git-Upload has no server. Requests go straight from your browser to the GitHub API, and your access token is kept only for the current session. Close the tab and it is gone.

Use a classic personal access token with the repo scope, and revoke it whenever you like from your GitHub settings.
