Git-Upload

Unggah file ke GitHub tanpa terminal.

Seret file atau zip, pilih repositori dan branch, lalu Git-Upload yang melakukan commit. Semua berjalan di browser kamu.

Hubungkan akun GitHub

Buat token di pengaturan GitHub dengan izin repo, lalu tempel di bawah. Token hanya disimpan selama tab terbuka dan tidak dikirim ke server mana pun selain GitHub.

  • Unggah fileKe repositori, branch, dan folder pilihanmu.
  • Ekstrak zipIsi zip langsung masuk tanpa folder pembungkus.
  • Repositori dan branchBuat baru, atau pilih dari daftar milikmu.
  • UnduhSatu file atau seluruh repositori dalam zip.
